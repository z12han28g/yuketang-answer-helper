# 雨课堂 AI 答题助手

一个开源的浏览器扩展（Chrome / Edge），用于自动检测雨课堂（yuketang.cn）的**课堂练习**，抓取题干和选项，并调用**你自己的 DeepSeek API** 实时生成答案与解析。

> ⚠️ 仅供学习交流使用。请遵守学校的学术诚信规定，本工具不鼓励用于任何形式的作弊。

> 📖 只想快速安装使用？请看 **[安装指南（普通用户版）](INSTALL.md)**，全程无代码。

## ✨ 功能

- 🔍 **自动检测**：每 3 秒扫描页面，练习一出现立即提醒（弹窗 + 语音）。
- 📖 **自动抓题**：提取题型、分值、题干、选项、填空位。
- 🤖 **三种工作模式**：不用 API（纯抓题）/ 用 API 半自动 / 用 API 全自动，由用户在设置弹窗分两步选择。
- 🔐 **隐私安全**：API Key 只保存在浏览器本地（chrome.storage），不上传任何服务器。
- 🎛️ **可视化设置**：点击扩展图标，在弹窗里选择工作模式，无需改代码。

## 🚀 安装

本扩展暂未上架商店，需通过「开发者模式」手动加载，全程约 2 分钟。

### 第一步：下载项目

任选一种方式获取项目文件夹：

- **方式 A（推荐，无需 git）**：在 GitHub 仓库页面点绿色的 **「Code」→「Download ZIP」**，下载后**解压**，得到一个 `yuketang-answer-helper` 文件夹。
- **方式 B（会 git）**：
  ```bash
  git clone https://github.com/z12han28g/yuketang-answer-helper.git
  ```

> ⚠️ 建议把解压出的 `yuketang-answer-helper` 文件夹**复制到桌面**，方便下一步选择（也避免路径太深选错层级）。

### 第二步：加载扩展

1. 打开浏览器扩展管理页：
   - **Chrome**：地址栏输入 `chrome://extensions`
   - **Edge**：地址栏输入 `edge://extensions`
2. 打开页面右上角的 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**（Edge 叫「加载解压缩的扩展」）。
4. 在弹出的选择框里，**手动选中 `yuketang-answer-helper` 文件夹**：
   - 先定位到**上一级目录**（能看到 `yuketang-answer-helper` 这个文件夹图标的层级）。
   - **单击选中**该文件夹（不要双击进入），然后点 **「选择文件夹」**。
5. 扩展列表出现 **「🛡️ 雨课堂 AI 答题助手」**，即加载成功。

### 第三步：填入 API Key

1. 点浏览器右上角 **拼图图标 🧩**，找到「雨课堂 AI 答题助手」。
2. 点旁边的 **📌 大头针** 把它固定到工具栏（以后点击更方便）。
3. 点击该扩展图标，弹出设置窗口。
4. 粘贴你的 **DeepSeek API Key**，点 **「保存设置」**，看到「✅ 已保存」即可。

### 第四步：开始使用

1. 打开雨课堂课堂页面（`yuketang.cn`）。
2. 老师发布练习后，扩展会自动检测并弹出答案面板。

> 验证是否生效：在雨课堂页面按 `F12` → Console，看到 `🛡️ 雨课堂 AI 答题助手已注入` 即说明扩展已运行。

### 常见问题

| 现象 | 解决方法 |
|------|----------|
| 找不到「加载已解压的扩展程序」按钮 | 确认「开发者模式」开关已打开 |
| 选择文件夹时报「找不到」 | 定位到**上一级目录**，只**单击选中**文件夹再点「选择文件夹」，不要双击进入 |
| 点扩展图标没反应 | 先把它用 📌 固定到工具栏再点 |
| 提示「未配置 API Key」 | 回第三步，确认 Key 已填且点了保存 |

## 🔑 获取 DeepSeek API Key

1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并登录。
2. 进入 **API Keys** 页面，创建密钥（形如 `sk-xxxx`）。
3. 充值少量余额（DeepSeek 按量计费，价格低廉）。

## 🖥️ 使用

1. 打开雨课堂课堂页面（`yuketang.cn`）。
2. 老师发布练习后，扩展会自动检测并弹出答案面板。
3. 点击面板任意处可关闭。

## 🎛️ 三种工作模式

在设置弹窗里，分两步选择工作模式：

**第一步 · 是否使用 AI**

| 模式 | 说明 |
|------|------|
| 不使用 API | 纯本地，检测练习并抓取题干/选项，不生成答案 |
| 使用 API | 调用 DeepSeek 生成答案与解析（需填 Key） |

**第二步 · 作答方式**（仅当选择「使用 API」时出现）

| 方式 | 说明 |
|------|------|
| 半自动 | AI 给答案，你手动填并提交 |
| 全自动 | AI 给答案 + 自动填 + 自动提交 |

## 🔧 自定义

| 配置项 | 位置 | 说明 |
|--------|------|------|
| 工作模式 | 扩展弹窗 | 不用 API / 用 API 半自动 / 用 API 全自动 |
| API Key | 扩展弹窗 | 你的 DeepSeek 密钥（仅「使用 API」时需填） |
| 模型 | 扩展弹窗 | `deepseek-chat`（快）/ `deepseek-reasoner`（强） |
| API 地址 | 扩展弹窗 | 默认 DeepSeek 官方，可改成兼容 OpenAI 格式的其他服务 |
| 声音提醒 | 扩展弹窗 | 开关，控制检测到练习 / 出答案时是否语音播报 |

## ⚠️ 关于「全自动」的说明

「全自动」模式下，扩展会在检测到课堂练习时自动填入 AI 生成的答案并点击提交。

> 🚨 请务必知悉：AI 生成的答案**可能回答有误**，自动提交后请自行核对作答结果。

## 🛠️ 技术栈

- **Manifest V3**（Service Worker + Content Script + Popup）

- DeepSeek API（OpenAI 兼容格式）
